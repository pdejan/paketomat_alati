# Paketomat Alati

Paketomat alati je aplikacija za radnike Pošta Srpske (Bosna i Hercegovina) koja olakšava rukovanje sa paketomatom prilkom punjenja/pražnjenja.
Aplikacija omogućava jednostavno čuvanje QR koda i šifre za prijavu na paketomat te generisanje CODE128 barkoda za posiljke koje se zbog oštećenja sopstvenog barkoda ne mogu skenirati na paketomatu.
